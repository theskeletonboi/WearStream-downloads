# WearStream download licenses

Bone Byte Tech publishes the official WearStream downloads in this repository. Each application is distributed under the license supplied with that version.

Windows 0.2.3 was the first Windows release distributed under the WearStream Proprietary Software License. It allows monetized streams, avatar creation, and client work. Redistributing or reselling copies of the software requires permission under that license. Earlier MIT grants and the licenses for third-party components continue to apply to the material they cover.

The macOS 0.2.0 download predates the Windows license transition. A release page can carry binaries from different platform versions. Consult the license for the particular download.

Read the [WearStream license and notices](https://wearstream.app/license/) for the current text and earlier licenses. For licensing permissions, contact [WearStream support](mailto:support@bonebytetech.com?subject=WearStream%20licensing).
